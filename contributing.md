# Contribution Guidelines

These guidelines are for [Awesome Craft Mars](https://github.com/EdisonTKPcom/Awesome-Craft-Mars).

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding an entry

- Search previous suggestions before making a new one, to avoid duplicates.
- The project must be open source with a public repository. If the licence is not OSI-approved, or the repository is archived or unmaintained, say so in the description.
- Use the format: `- [Name](https://github.com/owner/repo) - Short description.`
- Keep descriptions short, start with a capital letter, and end with a period.
- Add the entry in alphabetical order within the right category.
- Make one pull request per suggestion.
- Check your spelling and grammar, and remove trailing whitespace.
- Do not add company logos or wordmarks, and do not add unverified cost or performance claims.
- Dashboard figures and plan rows must be tagged FACT (measured, with a cited source and date), GOAL (a stated plan, not a result) or ESTIMATE (a sum or count we computed). Never present a target landing date or settlement timeline as a fact.

## Updating the list

Improvements to categories, removal of dead or unmaintained projects, and corrections to plan citations are welcome. Open an issue or pull request.

Thank you for your suggestions!
